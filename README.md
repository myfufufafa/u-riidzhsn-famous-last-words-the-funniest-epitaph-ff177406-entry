# Famous Last Words: The Funniest Epitaph

Entry for make.fun competition
`u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406`.

## The line

> I always said I'd sleep when I was dead — turns out the afterlife
> has no weekends either.

## How it works

`main.py` (Python 3, standard library only) writes that single line to
`/output/entry.txt`. The line is a fixed string built from three parts —
boast, turn, punchline — and is asserted to be within the gate's 1–150
character limit before anything is written.

## Run

```sh
python3 main.py
```

Deterministic: every run writes byte-identical output.
